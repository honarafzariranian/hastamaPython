# Functional difference report — Python reference vs Laravel/Vue

**Audit date:** 2026-10-03  
**Reference backend/UI:** FastAPI routes, Jinja templates and vanilla JS under `app/`  
**Target:** Laravel routes/controllers and Vue under `laravel/`

This report records source-confirmed deltas and workflows that could not be exercised. A route existing in both applications is not treated as proof of equal method, payload, status, authorization, response, side effects or data result. The full page inventory is in `PAGE_PARITY_MATRIX.md`.
